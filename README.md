# Flutter Internship – Task 4

## Task Title
Create a Registration Screen with Input Validation

## Description
This project is a professional Registration Screen developed using Flutter and Dart. It allows users to enter their personal information and create an account with proper input validation.

## Features
- Full Name field
- Email Address validation
- Phone Number validation
- Password field with Show/Hide functionality
- Confirm Password validation
- Gender Selection Dropdown
- Terms & Conditions Checkbox
- Register Button
- Success and Error Messages
- Responsive and Scrollable UI
- Login Option

## Technologies Used
- Flutter
- Dart
- Material Design
- TextFormField
- TextEditingController
- Form
- GlobalKey
- Form Validation
- StatefulWidget
- setState

## Validation
- Full Name cannot be empty.
- Email must have a valid format.
- Phone number must contain valid digits.
- Password must contain at least 8 characters.
- Confirm Password must match Password.
- Terms & Conditions must be accepted.

## Registration Functionality
When all required information is valid, the application displays a Registration Successful message.

**Note:** This project uses frontend validation only. No backend or database integration is required.

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.
